# Приёмка Windows-версии

## Сборка и безопасность

- [ ] Release `win-x64` собирается с нулём предупреждений.
- [ ] Чистая Windows 11 VM запускает self-contained ZIP без установленного .NET.
- [ ] В publish-каталоге и ZIP отсутствует API key.
- [ ] После сохранения ключа приложение перезапускается и видит credential; другой Windows-пользователь расшифровать файл не может.
- [ ] Обычное закрытие во время звонка сначала корректно финализирует обе дорожки.

## Аудио

- [ ] «Весь системный звук» + микрофон: обе дорожки слышимы и имеют сопоставимую длительность.
- [ ] Выбранное приложение исключает параллельно играющий звук другого приложения.
- [ ] Проверены Chrome/Edge с Google Meet, Zoom и Teams.
- [ ] Для Teams Desktop отдельно проверен fallback на весь системный звук: известны конфигурации Windows, где process-loopback Teams возвращает тишину.
- [ ] Подключение/отключение USB-микрофона показывает понятную ошибку и не повреждает уже записанные данные.
- [ ] Проверены Bluetooth headset и встроенный микрофон.
- [ ] 60-минутный звонок не показывает заметный drift дорожек.

## OpenAI

- [ ] Без ключа локальная запись завершается успешно.
- [ ] Валидный ключ проходит **Проверить подключение**.
- [ ] Неверный ключ, 429 и offline не останавливают запись и не попадают в логи вместе с секретом.
- [ ] Две Realtime-сессии различают «Собеседник» и «Вы».
- [ ] Вопрос собеседника создаёт подсказку; реплика пользователя сама по себе её не создаёт.
- [ ] После звонка создаются `transcript.txt`, `transcript.live.json`, `analysis.json` и обновлённый `metadata.json`.
- [ ] Повторная обработка не затирает вручную изменённый `transcript.txt`.

## Скрытый режим

- [ ] Суфлёр не виден в screen share Microsoft Teams.
- [ ] Суфлёр не виден в screen share Zoom.
- [ ] Суфлёр не виден в Google Meet через Chrome и Edge.
- [ ] Суфлёр не виден в Windows Snipping Tool screen recording.
- [ ] Основное окно и live-окно повторно получают capture protection после пересоздания.
- [ ] В интерфейсе и документации нет обещания абсолютной невидимости.
